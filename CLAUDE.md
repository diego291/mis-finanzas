# Reglas para trabajar en este repositorio (Claude)

## Publicación automática (decisión de Diego, 13/11/2026)
- Al terminar cada mejora o arreglo en cualquier chat: commit + push **directo a `main`**, sin pedir aprobación ni usar ramas intermedias ni pull requests.
- Si el proyecto tiene número de versión (en el código, `sw.js` o el mensaje del commit), subirlo en cada cambio para que la app tome la versión nueva.
- Verificar una vez antes de subir (que cargue sin errores). Si algo sale mal, revertir el commit.

## Prohibido
- Subir datos reales o privados (nombres, códigos de acceso, respaldos, montos personales). El repositorio puede ser público.
